Welche Daten werden erfasst?

Bei jeder Meldung: GPS-Position, Kategorie, Zeitstempel. Optional: Name, Klasse, Verkehrsmittel.

Nur lokal auf deinem Gerät. Es werden keine Daten an Server übertragen.

Nur wenn du es willst – per QR-Code an die Lehrkraft.
